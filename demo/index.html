How it works

An auditor that has to show its work.

Most AI code review guesses. ProofBox runs the code. A finding only exists if an exploit test it wrote passes inside the sandbox.

  1. 01

    Fetch

    Paste a public repo link. The code is copied to the Vultr VM, never run there.

  2. 02

    Box

    A fresh container starts: no network, read only disk, no secrets, hard memory and time limits.

  3. 03

    Hunt

    The agent reads the code and calls Vultr Serverless Inference to suspect bugs.

  4. 04

    Prove

    For each suspect it writes an exploit test and runs it in the box. A pass is the only way in.

  5. 05

    Fix

    It writes a patch, reruns the proof (it must now fail) and the repo tests (they must pass).

  6. 06

    Sign

    The box is deleted. Every event is hash chained and signed. Export Markdown, SARIF or JSON.

from invoice_tools import load_template

  --pids-limit 128 \
